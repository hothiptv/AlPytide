AlPytide API Docs

Mở IDE Demo

Giới thiệu

AlPytide API cho phép nhúng môi trường thực thi Python client-side vào bất kỳ trang web HTML nào bằng Pyodide (WebAssembly) mà không cần máy chủ xử lý tác vụ tính toán nặng.

Tích hợp vào Web của bạn

Thêm đoạn mã CDN sau vào thẻ <head>:

<!-- Pyodide Engine -->
<script src="https://cdn.jsdelivr.net/npm/pyodide@0.26.2/pyodide.js"></script>
<!-- CodeMirror Editor -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/python/python.min.js"></script>
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.css">

REST API Endpoints

  • GET /api - Kiểm tra trạng thái máy chủ.
  • GET /docs - Trang tài liệu hướng dẫn.
