Giới thiệu Hệ thống Engine AlPytide API

AlPytide API là nền tảng điện toán đám mây cung cấp dịch vụ thực thi Python Realtime kết nối bằng WebSockets. Dịch vụ hỗ trợ nhúng dễ dàng vào mọi loại ứng dụng Web (Single Page Application, GitHub Pages, Vercel...).

Endpoint chính thức: https://alpytide.onrender.com
GET
/api/status

Trích xuất thông số trạng thái hoạt động của hệ thống Engine.

Cấu trúc dữ liệu trả về:
{
  "status": "online",
  "engine": "AlPytide Python Engine (Docker)",
  "version": "1.0.0",
  "timeout_limit": "15 seconds"
}
WebSocket
Socket.io Events

Các sự kiện Realtime được hỗ trợ qua giao thức Socket.io Client:

  • run_code (Emit): Gửi chuỗi nguồn mã Python sang máy chủ.
  • input_data (Emit): Truyền dữ liệu nhập luồng tiêu chuẩn (stdin).
  • output (On): Lắng nghe kết quả thực thi (stdout / stderr).
  • process_exit (On): Nhận thông báo khi tiến trình chạy hoàn tất.

Tích hợp vào Ứng dụng Client (JavaScript) 
<script src="https://cdn.socket.io/4.7.2/socket.io.min.js"></script>
<script>
  // Khởi tạo kết nối đến Server Engine AlPytide
  const socket = io('https://alpytide.onrender.com');

  // 1. Thực thi đoạn mã Python
  socket.emit('run_code', 'print("Engine AlPytide ready.")');

  // 2. Nhận luồng dữ liệu trả về
  socket.on('output', (res) => {
    if (res.type === 'stdout') {
      console.log('Output:', res.data);
    } else {
      console.error('Lỗi:', res.data);
    }
  });

  // 3. Theo dõi sự kiện hoàn tất tiến trình
  socket.on('process_exit', (data) => {
    console.log('Tiến trình hoàn tất với Mã Exit:', data.code);
  });
</script>
