Chưa có file .txt hoặc .json nào được tạo từ chương trình Python.

Chưa có biểu đồ nào được vẽ bằng Matplotlib.

Tài liệu API & Ví dụ Mẫu
1. Ví dụ vẽ biểu đồ (Matplotlib):
import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4], [10, 20, 25, 30])
plt.title("Biểu đồ doanh thu")
plt.savefig("chart.png") # Tự động gửi lên Tab Biểu đồ
2. Ví dụ Tạo & Ghi File TXT / JSON:
import json

data = {"status": "ok", "items": [1, 2, 3]}
with open("output.json", "w") as f:
    json.dump(data, f) # Xuất hiện ở Tab File Tạo Ra
3. Ví dụ Cơ Sở Dữ Liệu Python (SQLite3):
import sqlite3

conn = sqlite3.connect('database.db')
cursor = conn.cursor()
cursor.execute('CREATE TABLE IF NOT EXISTS users (id INT, name TEXT)')
cursor.execute('INSERT INTO users VALUES (1, "AlPytide User")')
conn.commit()
print("Đã lưu dữ liệu thành công!")
