Giới thiệu AlPytide API Engine

AlPytide API Server là hệ thống biên dịch và thực thi Python Realtime dựa trên công nghệ WebSockets. Giúp tích hợp trình chạy Python vào bất kỳ website nào (Neocities, GitHub Pages, Vercel...).

Host Endpoint: https://alpytide.onrender.com

GET /api/status

Kiểm tra trạng thái hoạt động của Engine.

URL:
https://alpytide.onrender.com/api/status
Response mẫu:
{
  "status": "online",
  "engine": "AlPytide Python Engine (Docker)",
  "version": "1.0.0",
  "timeout_limit": "15 seconds"
}
WebSocket Socket.io Connection

Kết nối trực tiếp tới Server Render qua Socket.io Client.

  • run_code (Emit): Gửi chuỗi code Python sang Server.
  • input_data (Emit): Gửi dữ liệu nhập (stdin).
  • output (On): Nhận dữ liệu đầu ra (stdout / stderr).
  • process_exit (On): Báo hiệu khi mã chạy xong.
Code tích hợp vào trang web của An
<script src="https://cdn.socket.io/4.7.2/socket.io.min.js"></script>
<script>
  // Kết nối tới Server AlPytide trên Render
  const socket = io('https://alpytide.onrender.com');

  // 1. Gửi code Python cần chạy
  socket.emit('run_code', 'print("Hello từ AlPytide Engine!")');

  // 2. Nhận kết quả Realtime
  socket.on('output', (res) => {
    if (res.type === 'stdout') {
      console.log('Output:', res.data);
    } else {
      console.error('Lỗi:', res.data);
    }
  });

  // 3. Lắng nghe khi chương trình kết thúc
  socket.on('process_exit', (data) => {
    console.log('Chương trình hoàn tất với mã:', data.code);
  });
</script>
