1. Tổng Quan API v1.2

AlPytide Engine v1.2 là nền tảng điện toán đám mây cung cấp môi trường Sandbox cách ly dựa trên Docker Container. Hệ thống cho phép thực thi thời gian thực mã Python, hỗ trợ đa tập tin, kết nối cơ sở dữ liệu và tự động trả về biểu đồ đồ họa qua WebSockets.

Timeout 1 Phút (60s)

Hệ thống gửi cảnh báo nếu tiến trình xử lý quá 60 giây và tự động hủy hoàn toàn tiến trình kéo dài quá 10 phút để tránh treo server.

Thư Viện Phong Phú

Tích hợp sẵn các thư viện: matplotlib, numpy, pandas, requests, firebase-admin, supabase,...

Đa Tập Tin & Xuất File

Cho phép đính kèm nhiều file code/data phụ trợ và tự động trả về các tập tin xuất dữ liệu (.txt, .json, .png).

2. Cơ Chế Hạn Ngạch, Đếm Lượt & Cooldown

Hệ thống áp dụng cơ chế tự động đếm lượt chạy và thời gian hồi (Rate Limit) bền vững dựa trên IP người dùng kết hợp lưu file local `rate_limits.json` phía Server:

Thông số hệ thống Giá trị quy định Mô tả chi tiết cơ chế hoạt động
Hạn ngạch thực thi 30 lượt / IP Mỗi thiết bị được cấp tối đa 30 lần yêu cầu chạy code Python. Dữ liệu này được lưu liên tục vào `localStorage` ở client.
Thời gian hồi (Cooldown) 3 phút (180 giây) Khi dùng hết 30 lượt, hệ thống kích hoạt thời gian đếm ngược 3 phút. Trong thời gian này, các yêu cầu `run_code` mới bị từ chối.
Cảnh báo Timeout 60 giây Mọi tiến trình xử lý liên tục quá 60 giây sẽ nhận cảnh báo từ server để tối ưu hóa thuật toán.
Tự động ngắt cứng 10 phút Tiến trình chạy vô hạn (vòng lặp lặp vô tận) kéo dài tới 10 phút sẽ bị Server ngắt đứt để bảo vệ tài nguyên.
Trạng Thái Lượt Dùng (Đồng Bộ LocalStorage):
30 / 30 Lượt
Lượt còn lại: 30 lượt Thời gian Reset Cooldown: Sẵn sàng

3. Tài Liệu Sự Kiện Socket.io Backend & Client Code

Dưới đây là các sự kiện chuẩn Socket.io để kết nối và nhận stream dữ liệu từ Server https://alpytide.onrender.com/:

1. Gửi Mã Nguồn Cần Chạy (`run_code`)
const socket = io("https://alpytide.onrender.com/");

// Gửi code chính cùng danh sách file phụ kèm theo
socket.emit('run_code', {
  mainCode: `import time\nprint("Đang xử lý dữ liệu...")\ntime.sleep(1)\nprint("Hoàn tất!")`,
  files: [
    { name: "data.txt", content: "Dữ liệu đầu vào" }
  ]
});
2. Cập Nhật Hạn Ngạch & Đếm Ngược (`rate_update`)
socket.on('rate_update', (data) => {
  // data: { runsLeft: 29, resetTime: 1726000000000, maxRuns: 30 }
  localStorage.setItem('alpytide_runsLeft', data.runsLeft);
  localStorage.setItem('alpytide_resetTime', data.resetTime || '');
  
  console.log(`Lượt còn lại: ${data.runsLeft}/${data.maxRuns}`);
});
3. Lắng Nghe Kết Quả Đầu Ra (`output`)
socket.on('output', (data) => {
  if (data.type === 'stdout') {
    console.log("[LOG]:", data.data);
  } else if (data.type === 'stderr') {
    console.error("[LỖI]:", data.data);
  }
});

4. Xuất Đồ Họa & Biểu Đồ Matplotlib

API v1.2 hỗ trợ tự động quét file hình ảnh được tạo ra trong tiến trình thi hành code (`.png`, `.jpg`). Hệ thống mã hóa Base64 và truyền qua sự kiện `charts_generated` để client hiển thị trực tiếp lên giao diện.

import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4], [10, 20, 25, 30], marker='o')
plt.title("Biểu Đồ Mẫu AlPytide Engine")
plt.savefig("chart.png") # Server sẽ tự động gửi file chart.png này về Web
print("Đã xuất biểu đồ thành công!")

5. Kết Nối Database Đa Nền Tảng Đám Mây

API AlPytide v1.2 được tích hợp đầy đủ các driver kết nối tới các dịch vụ Cloud Database phổ biến như Google Firebase Firestore, Supabase, MongoDB Atlas, PostgreSQL, MySQL. Bạn chỉ cần viết script Python kết nối tới SDK tương ứng trong mã nguồn.
