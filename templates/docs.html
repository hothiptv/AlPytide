Alpytide Engine & Editor

Tài liệu hướng dẫn nhúng Engine thực thi Python và Bộ soạn thảo mã nguồn gọn nhẹ vào dự án Web của bạn.

1. Thành Phần Hệ Thống
Python Engine (Backend)

Xử lý và chạy trực tiếp các lệnh Python qua Serverless API, trả kết quả Terminal tức thì.

AlPyedit UI (Frontend)

Khung gõ code hỗ trợ đếm dòng, highlight cú pháp Python, tự đóng ngoặc và menu chạm giữ.

2. Tích Hợp Thư Viện & API

4. Cú Pháp Hàm & API
Hàm / Phương thức Tham số Mô tả
Alpytide.init() (btnID, outputID) Khởi tạo kết nối API, tự mở/khóa nút RUN theo trạng thái Server.
Alpytide.run() (code, outputID, btnID) Gửi code Python lên server chạy và hiển thị kết quả Console Output.
copyCode() Không Sao chép đoạn mã bôi đen (hoặc toàn bộ code) vào Clipboard.
clearCode() Không Xóa toàn bộ văn bản trong Editor sau khi xác nhận.
onSearchInput() (keyword) Tìm và đánh dấu highlight từ khóa trực tiếp trên Editor.
