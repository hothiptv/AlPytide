Python API Engine Documentation

Thực thi Python Backend chuyên dụng cho Web IDE - Tránh lag máy khách

1. Endpoint Python API Engine
https://alpytide.onrender.com/api
2. Chi tiết các Thành Phần Giao Diện IDE
  • Nút RUN Nút Kích Hoạt Thực Thi: Dùng để bắt sự kiện người dùng bấm, thu thập mã từ Khung IDE và kích hoạt thư viện Alpytide gửi gói tin tới Server API.
  • Khung IDE Khung Soạn Thảo Code: Nơi người dùng nhập mã nguồn Python. Có thể dùng thẻ <textarea> cơ bản hoặc tích hợp Monaco Editor (VS Code Web Engine).
  • Khung Output Khung Hiển Thị Kết Quả: Hiển thị trạng thái kết nối real-time, phản hồi lệnh print() từ Python hoặc báo lỗi hệ thống nếu đứt kết nối.
3. Hướng dẫn kết nối API với từng thành phần
Bước 3.1: Nhúng CDN Thư viện Alpytide JS

Thêm thẻ script sau vào phần <head> của file HTML:

<script src="https://github.com/hothiptv/AlPytide/raw/refs/heads/main/templates/alpytide.js"></script>
Bước 3.2: Tạo Cấu Trúc HTML cho 3 Thành Phần
<!-- 1. Nút RUN CODE -->
<button id="runBtn" onclick="runPythonEngine()">▶ RUN CODE</button>

<!-- 2. Khung Soạn Thảo IDE -->
<textarea id="pythonIde" style="width:100%; height:150px;">print("Hello World!")</textarea>

<!-- 3. Khung Hiển Thị Output Console -->
<div id="outputConsole" style="background:#000; color:#0f0; padding:10px;"></div>
Bước 3.3: Viết Logic Kết Nối API Bằng JavaScript

Hàm kết nối sẽ lấy code từ Khung IDE, truyền qua Nút RUN và đẩy kết quả ra Khung Output:

<script>
async function runPythonEngine() {
    // Lấy dữ liệu mã nguồn từ Khung IDE
    const sourceCode = document.getElementById("pythonIde").value;
    
    // Gọi thư viện Alpytide truyền mã nguồn và định vị Khung Output (#outputConsole)
    // Hệ thống sẽ tự động gửi tới https://alpytide.onrender.com/api
    await Alpytide.run(sourceCode, "#outputConsole");
}
</script>
