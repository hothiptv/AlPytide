Python API Engine

Hệ thống API backend xử lý và thực thi code Python cho Web IDE

POST https://alpytide.onrender.com/api
1. Request Payload (JSON)
{
  "code": "import requests\nprint(requests.get('https://api.github.com').status_code)"
}
2. Response Output (JSON)
{
  "status": "success",
  "output": "200\n",
  "error": null
}
Cách nhúng vào HTML IDE của bạn

Gửi mã từ khung soạn thảo HTML tới Server API để tránh gây giật lag máy khách:

async function sendCodeToExecutionEngine(pythonSourceCode) {
    const response = await fetch('https://alpytide.onrender.com/api', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ code: pythonSourceCode })
    });
    
    const result = await response.json();
    if (result.status === "success") {
        console.log("Output từ Server:", result.output);
    } else {
        console.error("Lỗi:", result.error);
    }
}
