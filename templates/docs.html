🐍 Alpytide Python Engine Documentation

Tài liệu tích hợp Engine thực thi Python Serverless cho Web IDE

1. Server Endpoint
https://alpytide.onrender.com/api
2. Nhúng Thư Viện JS (CDN jsDelivr)

Thêm thẻ script sau vào phần <head> của trang web để xử lý kết nối không bị lỗi CORS:

<script src="https://cdn.jsdelivr.net/gh/hothiptv/AlPytide@main/templates/alpytide.js"></script>
3. Cú Pháp Sử Dụng Thư Viện Alpytide
Hàm / Phương thức Tham số truyền vào Mô tả chức năng
Alpytide.init() (runBtnSelector, outputSelector) Tự động kiểm tra trạng thái Server (Ping Check), tự động khóa nút RUN, hiển thị các thông báo:
• "API: Vui lòng chờ server được kết nối"
• "Đang khởi động API. Vui lòng đợi…" (Nút RUN sẽ mở khi kết nối xong)
Alpytide.run() (code, outputSelector, runBtnSelector) Gửi mã Python lên server thực thi. Hiển thị thông báo:
• "Đang thực thi code…"
• "Đã thực thi xong!" (kèm Output kết quả)
4. Ví Dụ Tích Hợp Hoàn Chỉnh (HTML & JS)
<!-- Thư viện Alpytide JS -->
<script src="https://cdn.jsdelivr.net/gh/hothiptv/AlPytide@main/templates/alpytide.js"></script>

<!-- Giao diện Nút RUN và Output -->
<button id="runBtn" disabled>▶ RUN CODE</button>
<div id="output">API: Vui lòng chờ server được kết nối</div>

<script>
    // 1. Kiểm tra kết nối ngay khi tải trang
    window.addEventListener("DOMContentLoaded", () => {
        Alpytide.init("#runBtn", "#output");
    });

    // 2. Chạy code Python
    async function execute() {
        const pythonCode = 'print("Hello World!")';
        await Alpytide.run(pythonCode, "#output", "#runBtn");
    }
</script>
