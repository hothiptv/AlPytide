Alpytide Engine & Editor

Tài liệu hướng dẫn nhúng Engine thực thi Python và Bộ soạn thảo mã nguồn gọn nhẹ (AlPyedit) phong cách VS Code vào dự án Web của bạn.

1. Thành Phần Hệ Thống
Python Engine (Backend)

Xử lý và chạy trực tiếp các lệnh Python qua Serverless API, trả kết quả Terminal tức thì.

AlPyedit UI (Frontend)

Khung gõ code hỗ trợ đếm dòng, highlight cú pháp Python, tự đóng ngoặc, Virtual Caret xám đen phẳng và Context Menu VS Code nhọn góc.

2. Tích Hợp Thư Viện & API
POST https://alpytide.onrender.com/api

4. Cú Pháp Hàm & API Chức Năng
Hàm / Phương thức Tham số Mô tả
Alpytide.init() (btnID, outputID) Khởi tạo kết nối API, tự động mở hoặc khóa nút RUN theo trạng thái Server.
Alpytide.run() (code, outputID, btnID) Gửi code Python lên server thực thi và hiển thị kết quả Console Output.
execCommand() (cmdName) Điều hướng chạy các lệnh hệ thống: 'cut', 'copy', 'paste', 'selectAll', 'clear'.
cutCode() Không Cắt đoạn văn bản được bôi đen và lưu vào Bộ nhớ tạm (Clipboard).
copyCode() Không Sao chép đoạn mã bôi đen (hoặc toàn bộ code) vào Clipboard.
pasteCode() Không Dán nội dung từ Clipboard vào vị trí con trỏ hiện tại trong Editor.
selectAllCode() Không Bôi đen toàn bộ nội dung trong Editor.
clearCode() Không Xóa sạch toàn bộ văn bản trong Editor sau khi người dùng xác nhận.
onSearchInput() (query) Tìm kiếm và highlight trực tiếp từ khóa khớp trên Editor.
